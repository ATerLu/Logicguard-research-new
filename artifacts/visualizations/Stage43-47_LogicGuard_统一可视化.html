Defense chain

Stage43–47 在同一条链上分别做什么

Stage46 是固定 LogicPoison 的回答层基线；Stage47 冻结前述参数后，专门检验知道防御逻辑的攻击者。

STAGE 43

检测 + 恢复

标题重合与实体漂移共同判风险；命中后从 trusted clean candidate 中替换。

STAGE 44

Clean 补证

保留恢复结果，再用 query BM25 追加 clean evidence 至 top-12。

STAGE 45

二跳补全

仅在多跳链不完整时，按桥实体追加第二跳候选至 top-14。

STAGE 46

真实回答验证

固定 prompt 渲染，运行回答、规则审计和按需 Judge。

STAGE 47

自适应压力测试

低漂移、候选碰撞、自然桥接分别攻击 detector、recovery 与来源覆盖。

Takeaways

一句话看懂当前 LogicGuard

已经成立

在 Stage46 固定 LogicPoison 攻击上，Stage43–45 将两个数据集的最终 ASR 都降到 0，并恢复部分可答性。

只能算缓解

Stage44/45 通过加入 clean evidence 稀释部分自适应攻击，但没有可靠识别或移除自然桥接 source。

尚未解决

关系/属性一致性、无 counterpart 来源、错误候选恢复，以及完整 corpus poisoning + reindex 仍需 Stage48 验证。

实验边界：Stage47 是 post-retrieval source perturbation，没有重新构建攻击后的 GraphRAG index；不能据此宣称对建图、embedding、community 或原始排名变化具备端到端鲁棒性。

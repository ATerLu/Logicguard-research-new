## 推荐阅读顺序

1. 先读 `01_GraphRAG与知识图谱攻击防御/`：GraphRAG under Fire、LogicPoison、HoG-GRAG、KEPo。
2. 再读 `02_RAG投毒与对抗攻击/`：Semantic Chameleon、RIPRAG、CamoDocs、ToxicRAG。当前没有明确对应 PoisonedRAG、BadRAG 的 PDF，见待同步清单。
3. 接着读 `03_可信证据_防御与恢复/`：RAGDefender、SURE-RAG、ReliableRAG、PRA-RAG、SeCon-RAG。
4. 然后读 `04_评测基准与审计/`：RAGMark、RAG-Safety-Bench、可靠性/证据审计论文。
5. 最后读 `05–07`，用于补齐隐私、系统效率、图推理和综述背景。

## 重要边界

- `08_项目研究笔记/` 中的内容是 LogicGuard 的二手整理、实验协议和复现审计，不等同于论文正文。
- `vendor/upstream/` 里的固定上游仓库属于代码资源，不计入论文数量；当前镜像没有该目录。
- 另一台设备的 `papers_2025_06_to_2026_06`（41 篇）和 `logicguard_research_paper`（30 篇）尚未在本机取得，不能直接加到总数。
- 目录分类是管理分类，不是对论文内容、发表状态或实验结论的重新认证；需要交叉分类时可加标签，避免多份复制。若调整库内主目录，须同步更新所有索引和阅读链接，不改原始来源目录。

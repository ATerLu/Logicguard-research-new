- **B1/B2：原有 80 篇。** 2026-10-10 从既有目录复制整理，保留原元数据及当时的正文核读说明；本次未重新认证其全部出版信息，也未改写原论文或原结论。
- **B3：新增 40 篇。** 2026-10-16 联网检索，核对官方论文页题名、作者、首次提交、当前版本与 PDF 标识，核读方法、实验/理论、关键表格及局限；数值均为作者报告，未执行复现。录用/出版备注标明为作者声明。

## 历史原位置

建库前，仓库内外 `papper/`、`papper2/` 四个目录共 160 份副本，对应 80 个 SHA-256 不同的 PDF；本库当时另复制 80 份，139,825,710 字节。原副本未删除。旧批次的 SHA-256 去重只判断字节相同，不构成对全部历史不同版本的重新鉴定；新增 40 篇已按论文身份复核。

## 后续如何维护

1. 新文献使用下一个 LG 编号及主分类内的下一个序号；先查论文标识和题名，再查哈希。
2. 同一论文更新版本时保留原 LG 身份，记录版本与校验值，不算新增研究。
3. 跨主题只选一个主分类，通过标签或解读交叉引用，不复制多份 PDF。
4. 索引、解读、PDF、哈希清单一同更新；移动资料库时保留相对目录。
5. 研究笔记不是论文，待同步清单不是本机已收录数量。
